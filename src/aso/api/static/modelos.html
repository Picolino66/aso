Modelos (catálogo de executores)

Fonte única dos executores em tempo de execução (ADR-0076): as variáveis ASO_EXECUTORS, ASO_CLI_COMMAND, ASO_LLM_* e ASO_CANDIDATE_COMMANDS só semeiam este catálogo enquanto não há arquivo salvo. As chaves de API ficam apenas em variáveis de ambiente — aqui se informa o nome da variável. Streaming e permissão de escrita são campos do perfil: o runtime monta as flags de cada CLI, não digite-as no comando.
